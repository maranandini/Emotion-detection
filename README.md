# Emotion Detection using CNN

## Project Description
This project is a real-time facial emotion detection system developed using Convolutional Neural Networks (CNN). It detects faces using OpenCV and predicts human emotions from facial expressions using a trained deep learning model.

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy

## Features
- Real-time face detection
- Emotion classification
- Webcam-based prediction
- CNN-based deep learning model

## Dataset
FER-2013 Facial Expression Dataset

## Emotions Detected
- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise

## How to Run

1. Install required libraries.
2. Place `model.h5` in the project folder.
3. Run the Python file.
4. The webcam will open and detect emotions.
